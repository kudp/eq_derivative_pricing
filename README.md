# 気温 × FTSE 相関ダッシュボード

日次の平均気温とFTSE 100終値の相関を可視化する、依存関係なしの静的Webダッシュボードです。過去データを平面上の散布図としてプロットし、単回帰の回帰線を重ね、入力した「明日の気温」からFTSE 100の予想ポイントを描画します。

## 使い方

1. `index.html` をブラウザで開きます。
2. 画面上部の「明日の気温」に予想気温を入力します。
3. 散布図で過去の気温とFTSE 100終値、回帰線、明日の予想ポイントを確認します。
4. サマリーカードで相関係数、決定係数、回帰式、予想値を確認します。
5. 右側の履歴テーブルでプロット元データを確認します。

## ローカル確認

```bash
python3 -m http.server 4173 --bind 127.0.0.1
```

その後、<http://127.0.0.1:4173/index.html> を開きます。

## 実装メモ

- 依存関係なしのHTML/CSS/JavaScript構成です。
- JavaScript内のサンプル日次データを使って相関係数、決定係数、回帰係数、RMSEを計算します。
- SVGで散布図、回帰線、予想ポイントを描画します。
- 明日の気温入力を変更すると、予想値とプロットが即時に更新されます。
- このアプリは相関と単回帰の可視化デモであり、投資助言や価格保証ではありません。
