# シンプル CVA プライサー

金利スワップのCVAを、Hull-White 1ファクターの短期金利シミュレーションとモンテカルロで概算する静的Webアプリです。Bloomberg端末風の配色で、ブラウザだけで実行できます。

## 使い方

1. `index.html` をブラウザで開きます。
2. 元本、満期、サイド、固定クーポン、回復率、Hull-Whiteパラメータ、クレジット・スプレッド、パス数を入力します。
3. `PRICE CVA` を押すと、CVA価格、平均EE、ピークEE、スワップNPV、95% PFE、期待エクスポージャーのチャートが表示されます。
4. `COPY` を押すと、評価サマリーをクリップボードへコピーできます。

## ローカル確認

```bash
python3 -m http.server 4173 --bind 127.0.0.1
```

その後、<http://127.0.0.1:4173/index.html> を開きます。

## 実装メモ

- 依存関係なしのHTML/CSS/JavaScript構成です。
- 乱数はシード固定の線形合同法を使い、画面ロード時にも再現可能な価格を表示します。
- CVAは各時点の正のエクスポージャー、割引係数、クレジット・スプレッドから導いたデフォルト強度、LGDを掛け合わせて推定します。
- 教育・デモ用途の簡易モデルであり、実取引や会計評価向けの完全なXVAライブラリではありません。
