# 気温変化率 × FTSE騰落率 回帰ダッシュボード

2025年6月のサンプルデータを使い、ロンドンの気温の日次変化率とFTSE 100の日次騰落率の関係を可視化する、依存関係なしの静的Webダッシュボードです。散布図に単回帰の回帰線を重ね、入力した「今日の気温」と「明日の気温予想」から明日のFTSE 100日次騰落率を推定します。

## 使い方

1. `index.html` をブラウザで開きます。
2. 画面上部の「今日の気温」と「明日の気温予想」を入力します。
3. アプリが `((明日の気温予想 - 今日の気温) / 今日の気温) × 100` で気温の日次変化率を計算します。
4. 散布図で2025年6月のサンプルデータ、回帰線、入力値に基づく予想ポイントを確認します。
5. サマリーカードで相関係数、決定係数、回帰式、予想騰落率を確認します。
6. 右側の履歴テーブルでプロット元データを確認します。

## ローカル確認

```bash
python3 -m http.server 4173 --bind 127.0.0.1
```

その後、<http://127.0.0.1:4173/index.html> を開きます。

## 実装メモ

- 依存関係なしのHTML/CSS/JavaScript構成です。
- JavaScript内の2025年6月サンプル日次データを使って、気温変化率、相関係数、決定係数、回帰係数、RMSEを計算します。
- SVGで散布図、回帰線、予想ポイントを描画します。
- 今日の気温または明日の気温予想を変更すると、予想騰落率とプロットが即時に更新されます。
- このアプリは相関と単回帰の可視化デモであり、投資助言や騰落率保証ではありません。
