# USD/JPY FX ニュースダッシュボード

USD/JPY（ドル円）のライブチャートと、Googleニュース由来の経済ニュース10件を並べて表示する静的Webダッシュボードです。ニュースごとに、見出しベースのAI風スコアリングでUSD/JPYへの影響を `UP` / `Down` として表示します。

## 使い方

1. `index.html` をブラウザで開きます。
2. 左側でUSD/JPYチャートを確認します。
3. 右側でGoogleニュースの経済ニュース10件を確認します。
4. 各ニュースのリンクをクリックすると、別タブでニュース元またはGoogleニュース検索を開けます。
5. `REFRESH` を押すとニュースを再取得します。

## ローカル確認

```bash
python3 -m http.server 4173 --bind 127.0.0.1
```

その後、<http://127.0.0.1:4173/index.html> を開きます。

## 実装メモ

- 依存関係なしのHTML/CSS/JavaScript構成です。
- チャートはTradingViewのUSD/JPY埋め込みウィジェットを利用します。
- ニュースはGoogleニュースRSSを取得し、ブラウザのCORS制約回避のためAllOriginsの公開プロキシを経由します。
- RSS取得に失敗した場合は、Googleニュース検索へのフォールバックリンク10件を表示します。
- `UP` / `Down` はニュース見出しに含まれる米金利、FRB、日銀、リスク選好・回避などのキーワードから判定する簡易ロジックです。投資助言ではありません。
